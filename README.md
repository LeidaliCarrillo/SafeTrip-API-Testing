# SafeTrip API Testing
🧪 Trip Reservation API – QA Testing Project
📌 Overview

This project focuses on performing both automated and manual quality assurance (QA) testing for a trip reservation system based on APIs. 
The goal was to ensure reliability, performance, and correctness of the system by validating endpoints, workflows, and data integrity.
-------------
🚀 Technologies Used
- Java – For automated test development
- Postman – For API testing and request validation
- Jira – For bug tracking and test case management
-------
🧩 Project Scope

The testing efforts covered key functionalities of a trip reservation system, including:

User authentication and authorization
- Trip search and availability
- Booking and reservation workflows
- Payment processing (mocked/test environment)
- Error handling and edge cases
-----------------------------------------
🔍 Testing Approach
- ✅ Manual Testing
- Designed and executed test cases based on requirements
- Performed exploratory testing to uncover edge cases
- Validated API responses, status codes, and data consistency
- Logged and tracked defects in Jira
-----
- 🤖 Automated Testing
- Developed automated test scripts in Java
- Validated API endpoints and response structures
- Implemented regression testing to ensure stability across updates
-----
🐞 Bug Tracking
- Identified, documented, and tracked issues using Jira
- Collaborated with developers to reproduce and resolve defects
- Verified bug fixes and performed retesting
-----
📊 Key Outcomes
- Improved API reliability and response accuracy
- Early detection of critical defects
- Enhanced test coverage through automation
- Streamlined QA workflow and reporting
